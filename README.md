# NSMBHD Shop

A native Nintendo 3DS homebrew directory for New Super Mario Bros. DS and New Super Mario Bros. 2 community projects.

## Current app
- Featured project directory
- Separate Nintendo DS and Nintendo 3DS project categories
- Project detail pages with creator, listed version/status, description and source page
- Catalog entries are based on the NSMBHD community wiki

## Downloads and permissions
The current build is a project directory, not a CIA host. It does not bundle game data or redistribute files. Project entries link to community source pages so users can check the creator's current release and permissions. Direct downloads will only be added when the creator has clearly authorized redistribution, or as patches that are intended to be applied to a game copy the user already owns.

## Catalog
Edit `catalog/catalog.json`. Keep the source page and status current. Do not add ROMs, Nintendo game data, or unauthorized full game copies.

## Build
Push to `main` or run the **Build 3DS CIA** workflow manually. The workflow builds `NSMBHD-Shop.cia`.
